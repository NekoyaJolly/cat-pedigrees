# 猫の血統書管理

Accessの登録・検索・親の呼び出しを引き継ぐWeb版です。PCでの入力と、339×239mmの台紙への印刷を優先しています。

## 利用できる操作

- 一覧からID、名前、所有者、繁殖者、摘要、父母ナンバー、誕生日で検索。猫種・色柄・性別で絞り込み、50件ずつ表示。
- 新規登録と既存記録の編集。本猫IDは保存時に決まります。
- 父猫ID・母猫IDから3世代を展開。「両親ID」では指定した猫の父母・祖先を同じ世代のままコピー。
- 祖先ナンバーが重複すると入力欄と印刷文字を青で表示。
- 保存、保存して印刷、保存・印刷してきょうだいを続ける。
- 339×239mmの印刷画面とPDF保存。文字の位置をmm単位で調整できます。

## 起動と接続

Node.js 22以上を使います。追加のアプリ用依存パッケージは導入していません。Prisma CLIだけは既存クライアントと同じ7.8.0を生成時に実行します。

```bash
npm ci
cp .env.example .env
# .envの接続先・利用者・秘密鍵を設定する
npm run db:generate
npm test
npm run typecheck
npm run build
npm start
```

本番では環境変数をホスティング側へ登録してください。`.env.example`の値は見本です。接続パスワードや秘密鍵をGitへ登録しないでください。接続はサーバーからPrismaで行い、ブラウザーへDB資格情報を渡しません。SupabaseのRLSは解除しません。

Supabase Authのメールログインを有効にし、Site URLを`APP_ORIGIN`、許可する戻り先を`APP_ORIGIN/auth/callback`に設定します。既定のメールリンクと、メールテンプレートに確認コードを載せた場合のコード入力に対応しています。`PEDIGREE_ALLOWED_EMAILS`にある人だけがログインできます。認証後のセッションは12時間です。利用者一覧から外すと次のリクエストから拒否します。プロジェクトで独自SMTPの送信設定と到達確認を済ませてください。

DB接続先にはSupabaseの直接接続またはセッションプーラーを使います。新規採番でトランザクション内のロックを使うため、トランザクションを分断する接続方式は使いません。接続数は`DATABASE_POOL_MAX`で調整できます。本番のTLSは接続先に合ったCA証明書で検証し、証明書検証を無効にしないでください。

## 保存時の扱い

Accessから対応づけた業務80項目のうち、本猫ID以外の79項目を保存します。GP系のフラッグは移行しません。画面に表示しない旧コードや曾祖父母の色柄も、編集時に保持します。既存の不定な日付は、その項目を変更しない限り保持します。

新規採番は同一トランザクション内のロックと一意制約で重複を防ぎます。添付Accessで使われた最大IDの704651までは予約し、それより大きい番号から発行します。保存操作の再送には同じUUIDを使って二重登録を避けます。既存編集は更新日時を照合し、他の画面の変更を上書きしません。

今後Accessから同じDBへ書き込む場合は、この採番処理を共有する設計が必要です。Accessの`DMax+1`をそのまま併用しないでください。

## データの照合基準

2026年10月の添付AccessとSupabaseの照合結果です。空文字をNULLへ、数値項目を数値へ揃え、対応する80項目を比較しました。

| 区分 | 件数 | 扱い |
|---|---:|---|
| AccessとSupabaseの80項目が一致 | 13,745 | 基準として使用 |
| 同じIDで内容が異なる | 67 | ユーザーの確認待ち。自動で上書きしない |
| Accessにだけ存在 | 55 | テスト登録を含む可能性があるため追加保留 |
| Supabaseにだけ存在 | 0 | 対応不要 |

実データ、所有者名、差分の詳細はこの公開リポジトリへ保存しません。この変更にはデータの取り込みや既存DBの書き換えを含めていません。

## 印刷

用紙は339×239mmです。倍率100%、余白なし、ヘッダー・フッターなしで出力します。プレビューには提供された台紙画像を表示しますが、通常は文字だけを出力します。「台紙画像も印刷する」は確認用です。

添付されたレポートのVBAには座標・レイアウト情報が含まれていないため、印字位置は台紙画像をもとに作成しています。初回は実際の台紙・プリンターで試し刷りを行ってください。位置調整は端末のブラウザーに保存されます。長い文字が枠を超える場合は印刷画面に表示します。

PDF保存ボタンは300dpiの画像を1ページのPDFに収め、ページ寸法を`1mm = 2.83465pt`で固定します。文字検索用のテキストは含みません。ブラウザーの印刷からPDFに保存する場合は、ブラウザーや印刷設定で用紙寸法が丸められることがあります。

## 検証

`npm test`で世代展開、コピー、日付、保存項目、重複ナンバー、セッション署名を確認します。`npm run typecheck`と`npm run build`で型とビルドを確認します。新しい登録を試すときは、実データと分離した検証用DBを接続してください。
