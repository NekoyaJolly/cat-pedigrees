# 血統書の印刷書体

2026年10月18日、本人が比較見本FのLibre Baskervilleを選択した。英字と数字をLibre Baskerville、日本語を見本と同じNoto系の明朝にする。配信容量を抑えるため、日本語向けのNoto Serif JPを使う。サイズは比較時の値を維持し、実印刷前に別途調整する。

| 対象 | 文字サイズ |
| --- | --- |
| 本猫の名前 | 12pt・太さ600 |
| 基本項目・父母・祖父母 | 10.5pt |
| 父母のその他コード | 9pt |
| 曾祖父母の名前・称号 | 9.3pt |
| 曾祖父母の番号 | 8.7pt |

用紙339×239mm、各項目の座標と枠、行間は従来どおり。広い字面で長い名前が折り返される場合も、勝手に文字を縮小しない。枠を超える場合は既存の警告で知らせ、サイズ・配置の次回調整の対象にする。

## 端末間の書体の一致

`public/fonts`へ同梱したWOFF2を印刷画面だけで読み込む。端末内の同名フォントやGoogle Fontsへの実行時通信には依存しない。和欧文の読み込みと配置が終わるまで、アプリの印刷・PDF保存ボタンを無効にする。読み込みに失敗した場合は再読み込みを案内し、代替書体のまま出力しない。PDF生成側でも同じ書体の読み込みを確認する。

通常の入力画面にフォントを指定せず、登録時には印刷フォントを取得しない。日本語フォントは日本語向けの配布ファイルから太さ400のデータを取り出し、対応する16,726文字を削らず配信用に圧縮した。髙・﨑・𠮷・邊・齋・邉を含むことを確認する。

## 配布元とライセンス

- Libre Baskerville：Google Fontsの[配布ファイル](https://github.com/google/fonts/tree/main/ofl/librebaskerville)。可変書体をWOFF2に変換。原作者の[リポジトリ](https://github.com/impallari/Libre-Baskerville)。
- Noto Serif JP：Google Fontsの[日本語向け配布ファイル](https://github.com/google/fonts/tree/main/ofl/notoserifjp)。太さ400を取り出してWOFF2に変換。
- それぞれのSIL Open Font License 1.1を、フォントと並べて原文のまま保存している。書体に含まれる著作権情報を維持する。

## 検証範囲

型チェックと本番用ビルド、既存の単体テスト11件に成功。合成DBとローカル認証によるブラウザー検証8項目に成功した。

- 登録画面では印刷フォントを取得しない。
- 和欧文2書体を読み込み、待機中は印刷・PDF保存を実行できない。
- 架空の祖先14頭、折り返す長い猫名、髙・﨑を含む氏名を、台紙あり・文字のみのPDFとブラウザー印刷へ出力する。
- 位置補正の保存・再表示・リセット。
- 幅390pxでも書体が揃い、印刷操作ができる。
- 長すぎる猫名が枠を超える場合の警告。
- 長すぎる祖先番号が枠を超える場合の警告。
- 書体取得失敗時の案内と、代替書体のままでの出力の防止。

保存したPDFは両形式とも1ページで、339×239mmと一致した。ブラウザーの印刷出力も1ページだが、検証用Chromiumでは用紙換算が339.0048×238.8443mmへ丸められた。寸法を固定した確認にはアプリのPDF保存を使用する。3種類の出力を画像へ変換し、文字と日本語の異体字、折り返し、欠けがないことを目視確認した。検証による実環境の血統データの追加・変更はない。

同梱する書体の対応文字は配布元から削っていない。著作権情報とライセンスを維持し、Libre Baskervilleは789文字、日本語用は16,726文字を確認した。以下は同梱ファイルのSHA-256。

| ファイル | 容量 | SHA-256 |
| --- | --- | --- |
| `libre-baskerville.woff2` | 64,068バイト | `e2fff63b2bb220744103e9b8364a33eb43e9392916582b4720b7ecac94ebacef` |
| `noto-serif-jp.woff2` | 3,088,908バイト | `bec20ad3d3dfa7ec9bbba6bd0267dd27e115c0036cfb13675227f6a98a1b393b` |

物理的な台紙への印刷、プリンターの倍率・余白、実機での文字の大きさは、この変更だけでは確定しない。書体が揃ったPreviewでサイズを決めてから試し刷りする。
