# 血統書の印刷書体

2026年10月18日、本人が比較見本FのLibre Baskervilleを選択した。その後「血統書に日本語を印字しない」と確認できたため、印刷はLibre Baskervilleだけにする。Noto Serif JPの指定・読み込み・配布ファイルは削除した。選定時のサイズを基準に、2026年10月19日に受領した配置編集の指定で本猫の登録番号・所有者・繁殖者を11ptへ調整した。

| 対象 | 文字サイズ |
| --- | --- |
| 本猫の名前 | 12pt・太さ600 |
| 基本項目・父母・祖父母 | 10.5pt |
| 本猫の登録番号・所有者・繁殖者 | 11pt |
| 父母のその他コード | 9pt |
| 曾祖父母の名前・称号 | 9.3pt |
| 曾祖父母の番号 | 8.7pt |

用紙は339×239mm。各項目の位置と枠は[受領した印字位置の反映記録](print-layout-adjustments.md)に従う。長い名前を勝手に縮小しない。枠を超える場合は既存の警告で知らせる。今回渡した[印字位置の配置編集](print-layout-editor.md)で、次の配置・文字サイズを指定できる。

## 端末間の書体の一致

`public/fonts/libre-baskerville.woff2`を印刷画面だけで読み込む。端末内の同名フォントやGoogle Fontsへの実行時通信には依存しない。読み込みと配置が終わるまで、アプリの印刷・PDF保存ボタンを無効にする。取得失敗時は再読み込みを案内し、代替書体のまま出力しない。PDF生成側でも同じ書体の読み込みを確認する。

通常の入力画面は変更せず、登録時には印刷フォントを取得しない。

## 配布元とライセンス

Libre BaskervilleはGoogle Fontsの[配布ファイル](https://github.com/google/fonts/tree/main/ofl/librebaskerville)をWOFF2へ変換した。原作者の[リポジトリ](https://github.com/impallari/Libre-Baskerville)。対応する789文字と著作権情報を維持し、SIL Open Font License 1.1をフォントと並べて原文のまま保存している。

| ファイル | 容量 | SHA-256 |
| --- | --- | --- |
| `libre-baskerville.woff2` | 64,068バイト | `e2fff63b2bb220744103e9b8364a33eb43e9392916582b4720b7ecac94ebacef` |

## 日本語書体を除去した後の検証

型チェックを含む本番用ビルド、既存の単体テスト11件、合成DBとローカル認証によるブラウザー検証9項目に成功した。

- 登録画面では印刷フォントを取得しない。
- Libre Baskervilleだけを取得し、本猫12pt・基本10.5ptで表示する。待機中は印刷・PDF保存が無効。
- 固定台紙と67個の印字要素を、元DOM・データ項目へ対応付けて採取する。
- 架空の祖先14頭、両親の名前の続き、欧文の所有者・繁殖者を、台紙あり・文字のみのPDFとブラウザー印刷へ出力する。
- 位置補正の保存・再表示・リセット。
- 幅390pxでも書体が揃い、印刷操作ができる。
- 長すぎる猫名が枠を超える場合の警告。
- 長すぎる祖先番号が枠を超える場合の警告。
- 書体取得失敗時の案内と、代替書体のままでの出力の防止。

保存PDFは両形式とも1ページ、339.0005×239.0004mm。検証用Chromiumのブラウザー印刷も1ページで、339.0053×238.8447mmへ丸められた。寸法を固定した確認にはアプリのPDF保存を使用する。検証による実環境の血統データの追加・変更はない。

初回の書体選定時のPreviewは`5b65df37a5f7a41c14feb0c45260689ab23a25c1`・`dpl_2KjDTjjF6r5jWet5JNc7kLyFu6y8`で確認した。日本語書体の除去はその後続変更で、最新の確認先と反映状況は[PR #3](https://github.com/NekoyaJolly/cat-pedigrees/pull/3)に記録する。

物理的な台紙への印刷、プリンターの倍率・余白、実機での文字の大きさは未確定。配置とサイズを決めてから試し刷りする。
