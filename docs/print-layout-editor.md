# 血統書の印字位置を編集する資料

本人の依頼で`rearrange-ui`を使用し、印刷プレビューの台紙上にある67個の印字を動かせる、通信不要の編集HTMLを作成した。339×239mmの台紙と印字だけを対象にする。HTMLにはLibre Baskervilleを埋め込み、元の空台紙を固定している。見本の猫・祖先14頭・所有者・繁殖者はすべて架空。登録データの編集機能や認証情報は含めない。

## 採取した基準

実装`ebe5ef622651ccc1e76c496591797e48e076c678`へ日本語書体の除去差分を加えたローカル画面を使用した。位置や文字サイズの変更は加えていない。採取時の`certificate-print.css`のSHA-256は`57f446cb716929677a862020a5e15e33f8027dc575e6644ed4953a31e2b7b3e1`。

同梱の`capture_dom.cjs`で実DOMを採取し、各印字の親ブロックの矩形と書体を実測して`build_editor.py`へ渡した。文字を含む画面キャプチャを背景には使わず、`public/certificate-template.jpg`を使うため、文字を動かしても元の文字は残らない。文字ブロック内の折り返しにはブラウザーによる差があり、長い実データの確認は実装後にも行う。

| 対象 | 編集要素IDの例 | 元の実装・項目 |
| --- | --- | --- |
| 本猫の称号と名前 | `print-self-name` | `CertificatePrint.tsx`の`record.title`・`catName`・`catName2`を連結した枠 |
| 所有者・繁殖者 | `print-owner`・`print-breeder` | `record.ownerName`・`record.breederName` |
| 父母 | `print-father-name`・`print-mother-number`等 | `Ancestor`の父・母。それぞれ称号、猫名、続き、毛色、目色、番号、他団体番号 |
| 祖父母 | `print-ff-name`等 | 関係`ff`・`fm`・`mf`・`mm`の称号、猫名、毛色、番号 |
| 曾祖父母 | `print-fff-name`等 | 8関係の称号、猫名、番号 |
| 台紙 | `print-paper` | 元画像。編集開始時は固定 |

その他の基本項目も個別に保持する。各要素の`sourceRef`にコンポーネント、データの参照先、採取時のDOMセレクターがあり、編集前の`baseline`と変更後の`scene`を同じ要素IDで保存する。

## 単位と反映方法

調整欄は位置・幅・高さ・余白がmm、文字サイズがpt。ドラッグの吸着と矢印は0.1mm、Shift＋矢印は1mm。内部データはスキル標準のCSS pxで保持し、1mm＝96/25.4 CSS px、1pt＝4/3 CSS pxで変換する。PDF側の1mm＝72/25.4ptとも対応する。画面の表示倍率は編集対象の用紙寸法を変えない。

これは固定用紙の印字位置を決める資料なので、受領後は左上原点のmm座標へ戻す。祖先の各行は元実装では縦積みのため、個別移動を反映する際は称号・名前・番号の対応を保ち、他の行を意図せずずらさない。編集用のグループ化や台紙の固定をアプリの業務機能へ追加しない。架空の文字列をDBの値へ反映しない。

「AIへ渡す」の説明を貼り付けてもらうか、保存されたHTML・JSONから同梱の`read_edits.py`で変更データだけを読み取る。利用者から返されたHTML自体は実行しない。反映時に実装の版を照合し、最終のPDFとブラウザー印刷を確認する。

## 検証

同じ倍率で元画面と再構成を比較し、文字の位置・書体と台紙を目視確認した。67個の印字と台紙の対応、ドラッグ、サイズ変更、mm位置・ptサイズの入力、文字編集、非表示、Undo／Redo、複数選択、グループ移動、整列、「AIへ渡す」の単位と出典、保存したHTMLとJSONの再読込を確認した。保存後も変更前の基準と要素IDは維持され、外部への通信とブラウザーエラーはなかった。物理的な台紙への印刷は未確認。
